# Clearbook Lite

Concept preview of a phone companion for advice-only financial planners. Static page, sample data only.

Open index.html, or the GitHub Pages site.

## Step-by-step walkthrough

Tap the round ? button in the app (or "Start the step-by-step walkthrough" beside the phone, or open the page with `?tour=1`). Twenty named steps spotlight each part and explain what it does. On "your turn" steps the spot glows and waits for your own tap; the walkthrough never taps anything for you. Back, Skip, Esc and the arrow keys work. Reduced motion keeps every step without the animation.
